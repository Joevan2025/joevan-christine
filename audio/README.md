# Songs go here

Drop MP3s into this folder with these exact names:

| File | Moment |
|---|---|
| `01-processional.mp3` | Processional |
| `02-bride-entrance.mp3` | Bride's entrance |
| `03-first-dance.mp3` | First dance |
| `04-last-song.mp3` | Last song |

Then open `js/config.js`, find `TRACKS`, and type each song's `title` and `artist`.

Keep files at 128 kbps and under about 5 MB each. A song that is not here yet shows "coming soon" and its play button is greyed out.
