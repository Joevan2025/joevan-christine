# Photos go here

Upload your pictures into this folder using these names:

| Name | Where it shows |
|---|---|
| `prenup-01` … `prenup-06` | The six arched frames in "Before the day". Any orientation works; portrait looks best (the frame is 4:5). |
| `hero` (optional) | Shows very faintly inside the arch behind your names at the top. Portrait, about 1600×2000. |
| `video-poster` (optional) | The still shown before someone presses play on the film. 1280×720. |
| `og.jpg` | The picture people see when the link is shared on Messenger, Viber or WhatsApp. 1200×630. |

## About the file type

For everything except `og.jpg`, the extension does not matter — **`.jpg`, `.png`, `.jpeg` and
`.webp` all work**. So `prenup-01.png` is just as good as `prenup-01.jpg`.

Two things that *do* matter:

- **Use lowercase.** `prenup-01.PNG` will not be found; `prenup-01.png` will.
- **`og.jpg` must genuinely be named `og.jpg`.** Link previews are read by Facebook and Viber
  before anyone opens the page, so that one cannot fall back to another extension.

Keep each file under about 400 KB so the site stays fast on phones — <https://squoosh.app>
shrinks them for free.

Anything missing simply shows a drawing until you add it. No code changes needed.
