# Photos go here

Drop your prenup pictures into this folder with these exact names:

| File | Where it shows |
|---|---|
| `prenup-01.jpg` … `prenup-06.jpg` | The six arched frames in "Before the day". Any orientation works; portrait looks best (the frame is 4:5). |
| `hero.jpg` (optional) | Shows very faintly inside the arch behind your names at the top. Portrait, about 1600×2000. |
| `video-poster.jpg` (optional) | The still shown before someone presses play on the film. 1280×720. |
| `og.jpg` | The picture people see when the link is shared on Messenger, Viber or WhatsApp. 1200×630. Pick your favourite. |

Keep each file under about 400 KB so the page stays fast on phones (squoosh.app is an easy free resizer).

Anything that is missing simply shows a drawing until you add it. No code changes needed.
